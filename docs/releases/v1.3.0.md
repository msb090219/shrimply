# Shrimply v1.3.0 — Windows and Mac beta

Unshrimp is now **Shrimply** — don't get shrimped.

## What's new

- A clearer Dashboard with monitored time, weekly posture summaries and a
  26-week activity calendar.
- Dashboard and Settings in one window, with a collapsible sidebar.
- Horizontal or vertical floating posture meters, with size, placement,
  transparency and motion controls.
- A shrimp or discreet text cue that responds to sustained poor posture,
  with adjustable appearance and recovery delays.
- Sitting-based break reminders with configurable intervals and break lengths.
- Clearer calibration guidance, camera recovery, Light/Dark/device themes,
  and more consistent previews and controls.
- Safer startup settings, calibration saves and history persistence.

## Downloads

| Platform | Download |
| --- | --- |
| Windows · 64-bit | `shrimply-win64.zip` |
| macOS 15+ · Intel Macs | `shrimply-macos-x86_64.zip` |

Both downloads include the app and posture models. Python is not required.

**Windows:** extract the entire ZIP and open `shrimply/shrimply.exe`.
Windows may show a SmartScreen warning because the app is unsigned.

**Mac:** extract the ZIP, move `Shrimply.app` to Applications and open it.
This first Mac beta is unsigned and not notarized. If macOS blocks it and you
trust the download, follow [Apple's opening instructions](https://support.apple.com/en-nz/102445)
using System Settings → Privacy & Security → Open Anyway. Allow camera access
when you choose to calibrate. The Mac app includes native menu-bar controls,
login startup and sleep handling, plus an aspect-preserving camera preview.

## Upgrading from Unshrimp

Quit Unshrimp from its tray menu before opening Shrimply. Existing settings,
calibration and history carry over to Shrimply; the old files are kept.
Data lives in `%APPDATA%\Shrimply` on Windows or
`~/Library/Application Support/Shrimply` on Mac. An enabled login entry is
updated to the new app location.
Keep the extracted app in a permanent location if you enable startup at login.

Closing the main window leaves Shrimply in the system tray. Choose **Quit**
from the tray menu to exit completely.

## Privacy and limitations

Camera processing stays on your device; camera frames are not saved. The bundled
MediaPipe Tasks SDK sends performance and usage metrics to Google. Shrimply is a
habit reminder, not a medical device. Lighting, framing and occlusion can affect
posture detection; recalibrate after moving your camera or chair.

This is a beta: please report problems with your OS, app version and steps to
reproduce them. The Mac package has been verified on Intel; other Mac
architectures have not been verified. Clean-machine and longer-use feedback
are welcome.
